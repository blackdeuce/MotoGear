MOTOGEAR - PHASE 1 FRONTEND

Folder structure:
MotoGear/
|-- index.html
|-- css/
|   `-- style.css
|-- js/
|   `-- script.js
|-- assets/
|   `-- images/
`-- README.txt

RUN LOCALLY:
1. Extract the MotoGear.zip file.
2. Open the MotoGear folder in Visual Studio Code.
3. Install the "Live Server" extension.
4. Right-click index.html and select "Open with Live Server".
5. The site should open at a local address such as http://127.0.0.1:5500.

NOTES:
- The accessories page is display-only. There is no cart, search, checkout, or admin page.
- The login and registration forms are frontend demos only.
- Demo registration stores the test account in browser memory and it disappears on refresh.
- Do not use real passwords with this demo.
- Real authentication and PostgreSQL storage will be implemented in later phases.
- The remote Unsplash images require an internet connection.
